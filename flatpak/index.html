XFB flatpak repository

Install XFB, and receive every later release through flatpak update:

flatpak install https://netpack.github.io/XFB/flatpak/xfb.flatpakref

Or add the repository and install from it by name:

flatpak remote-add --user --if-not-exists xfb https://netpack.github.io/XFB/flatpak/xfb.flatpakrepo
flatpak install --user xfb pt.netpack.XFB

The repository is not signed. Architectures: x86_64 and aarch64. github.com/netpack/XFB
